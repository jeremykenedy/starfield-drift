# Starfield Drift 1.0.0

First stable release of the animated starfield screensaver.

## Included

- Procedurally rendered stars with depth drift, continuous twinkle, and optional meteor trails.
- Sparse, balanced, dense, and packed star counts; three palettes; three drift speeds; three star brightness levels; and meteor frequency controls.
- Per-setting random choices and a master randomize option.
- A remote-friendly settings activity and a validated settings provider for host applications.
- A guided standalone ADB installer with signed release download, SHA-256 verification, update, local APK install, and explicit uninstall.
- No ads, analytics, telemetry, crash reporting, tracking, runtime network permission, or runtime network requests.

## Compatibility

Android 6.0 (API 23) or later with DreamService support. The Android TV emulator verification used Android 12/API 31 at 1920x1080. Physical Fire TV and Google TV devices were not tested for this release. Details and limits are in [device verification](../VERIFICATION.md).

## Install

Connect a TV over ADB and run:

```bash
python3 install.py --serial TV_IP:5555
```

The installer downloads the latest signed APK from this repository and verifies its SHA-256 checksum. For manual installation, download `starfield-drift.apk` and `starfield-drift.apk.sha256` from the release, then verify with:

```bash
shasum -a 256 -c starfield-drift.apk.sha256
```

Select Starfield Drift in the TV's screensaver settings after installation. The installer does not change screensaver selection or system timers. See the [installation guide](../INSTALLATION.md).

## Upgrade path

There is no earlier public version. This release installs as a fresh app. Future upgrades must keep the same package ID and signing certificate; install over the existing app to preserve settings.

## Changes

No breaking changes. This release establishes version `1.0.0` and Android version code `1`. There is no earlier public command or upgrade behavior to preserve.
